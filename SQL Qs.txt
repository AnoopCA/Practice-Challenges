1.  What is SQL?
    ○  Explain what SQL is and its importance in database management systems.
        SQL is a declarative programming language used to manage and manipulate data in relational databases. It allows users to store, retrieve, update, and delete data efficiently. SQL is essential in database management because it ensures data integrity, security, and organization. It helps in creating database structures, controlling user access, and handling transactions to maintain accuracy.

2.  Overview of MySQL and its Features:
    ○  List and describe at least five key features of MySQL.
        Open-Source – MySQL is freely available, making it cost-effective and widely used.
        Relational Database Management System (RDBMS) – It organizes data into tables with relationships, ensuring structured and efficient data storage.
        High Performance – MySQL is optimized for speed and handles large volumes of data efficiently, making it ideal for web applications.
        Scalability – It supports scaling both vertically (adding resources to a single server) and horizontally (distributing data across multiple servers).
        Cross-Platform Compatibility – MySQL runs on various operating systems, including Windows, Linux, and macOS, making it highly flexible.

4.  Basic Concepts:
    ○  Define the following database concepts: Table, Row, Column. 
        Table: A table is like a spreadsheet or a grid where data is stored in rows and columns. It organizes related information in a structured way.
        Row: A row is a single, horizontal line of data in a table. Each row represents a unique record or entry in the table.
        Column: A column is a vertical section in a table that holds a specific type of data, such as names, dates, or prices. Each column is labeled with a heading that describes the data it contains.
